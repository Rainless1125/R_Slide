# 企業 / 品牌識別圖示

把公司或品牌的識別圖片（Logo、標章等）放在這個資料夾，所有使用者都能在編輯簡報時，從「品牌」按鈕插入。

- 支援 PNG、JPG、WebP、GIF、SVG，每個檔案最大 15 MB。
- 選單上顯示的名稱是檔名（不含副檔名），例如 `公司 Logo（橫式）.png`。選單依檔名排序。
- 只讀取這個資料夾的第一層，子資料夾與以 `.` 開頭的檔案會略過。
- 新增或刪除圖片後不需要重新啟動服務。
- 資料夾中沒有圖片時，畫面上不顯示「品牌」按鈕。
- 插入後的圖片會存在簡報裡，之後替換或刪除這裡的檔案，不會影響已插入的簡報。
- 透明背景的 Logo 建議用 PNG 或 SVG。
