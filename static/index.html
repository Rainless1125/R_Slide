        使用教學

        三個步驟：輸入素材 → 審查頁面 → 播放、編輯與匯出

        歡迎使用 R Slide

        貼上文字素材，AI 會依內容自動規劃版面並產生可編輯的簡報，完成後可直接播放，或匯出為 PDF、PowerPoint、HTML。

        1. 01 / 輸入貼上或上傳素材，選擇簡報模式、頁數與視覺風格，按「生成」。
        2. 02 / 審查瀏覽每一頁的縮圖，修改標題、刪除或調整順序，不滿意的頁面可單獨重產。
        3. 03 / 簡報全螢幕播放、撰寫講者備註、進入編輯模式微調內容，最後匯出。
        畫面上方的步驟條可隨時點擊，在三個步驟之間切換；生成與重產需要先登入帳號。

        輸入素材

        • 輸入文字：直接在輸入框貼上內容（上限 50,000 字），或點「試試範例」快速體驗。
        • 匯入檔案：點「上傳檔案」、拖放或貼上 PDF、Word（.docx）、Markdown、TXT（單檔 10 MB）；文字抽出後會先填入輸入框，可檢查、修改再生成。掃描影像型 PDF 與舊版 .doc 不支援。
        • AI 模型：右上角的模型選單可切換 Gemini、OpenAI 或 Databricks 的模型（依伺服器設定而定）。
        簡報模式
        簡易模式 · 演講型少字大圖、一頁一重點，論述細節寫進講者備註，適合上台報告。
        詳細模式 · 閱讀型以結論句當標題、附完整論述與數據出處，不需講者也能看懂，適合會後寄送。
        其他選項
        • 頁數：可指定 2~12 頁或由 AI 決定；詳細模式資訊量較大，素材豐富時建議由 AI 決定。
        • 受眾與視覺風格：例如「主管會議」「蘋果極簡白」「科技深色風」，AI 會依此調整語氣與配色。
        先確認大綱（選用）
        • 開啟生成按鈕旁的「先確認大綱」，AI 會先列出每頁的標題、重點與建議版型。
        • 可直接修改文字（重點一行一點）、用箭頭調整頁序、新增或刪除頁面；確認後按「依大綱生成簡報」（Ctrl / ⌘ + Enter）。
        • 確認大綱期間仍可更換風格、受眾與模型，生成時會套用輸入區當下的設定。
        • 產生大綱與生成簡報各算一次用量；想省事就關閉此選項，直接生成整份簡報。
        按 Ctrl / ⌘ + Enter 可快速生成；輸入內容會自動保存為草稿。

        審查與重產

        生成後會進入審查頁，以卡片列出每一頁的縮圖與標題。

        • 修改標題：直接點擊卡片上的標題文字修改，Enter 確定、Esc 取消。
        • 調整頁序與刪除：拖曳卡片左上角的把手，或用左右箭頭前移 / 後移；「刪除」可移除該頁。
        • 新增空白頁：每張卡片的「+」可在該頁後新增空白頁，最後一格可新增到最後；空白頁沿用參考頁的背景與文字顏色。
        • 重產此頁：對某頁不滿意時，可輸入提示詞（例如「重點三點式、加上 KPI 資訊卡」）單獨重新生成，其他頁面維持不變。
        • 切換模式重產：重產視窗可改用另一種簡報模式，之後這份簡報的重產都會沿用。
        想放自己的圖片時，可先在重產提示詞中說明「右半邊留白，之後放產品照片」，再到編輯模式插入圖片並拖曳到留白處。

        播放與講者

        • 換頁：工具列的左右箭頭、鍵盤 ← →、簡報筆（PageUp / PageDown），或在觸控螢幕上左右滑動。
        • 全螢幕：按「全螢幕」或 F；自動播放：按「自動播放」或空白鍵。
        • 講者備註：AI 會為每頁產生口語化講稿，按「備註」或 N 顯示在投影片下方，可直接修改；備註會寫入 PPTX 的備忘稿。
        • 講者檢視：按「講者檢視」或 P 另開視窗，顯示目前頁、下一頁、備註與計時器，適合主畫面投影、筆電看講稿。
        開啟講者檢視後，將主視窗拖到投影機畫面並按 F 全螢幕，在講者檢視中換頁即可同步。

        編輯模式

        在簡報頁按「編輯」進入編輯模式，直接修改投影片內容，不會呼叫 AI。

        修改 AI 生成的版面
        • 點擊文字即可修改；選取元素後，格式工具列可調整字級、粗細、對齊、顏色與圓角，或複製、刪除、調整同層順序。
        • AI 生成的元素位置與大小固定；AI 產生的圖表可修改數據。
        插入內容
        文字插入可自由移動的文字方塊。
        圖片上傳、拖放或貼上圖片，在瀏覽器端壓縮後內嵌。
        圖表以試算表輸入數據，可直接貼上 Excel 多格資料，並可加參考虛線。
        圖示內建 300 個常用圖示，可用中英文關鍵字搜尋，Enter 插入第一個。
        圖案16 種圖案，可調整填滿、外框、線條樣式與圓角，雙擊輸入文字。
        空白頁在目前頁面之後新增空白頁並直接切換過去。
        擺放與微調
        • 自行插入的內容可拖曳移動、拉角落縮放，會自動對齊邊緣、中線與其他元素（按住 Alt 暫停吸附）。
        • 選取後用方向鍵微調位置（Shift 一次 10px）；Delete 刪除、Esc 取消選取。
        • 操作失誤可按「撤銷」「重做」，或使用 Ctrl + Z / Ctrl + Shift + Z。

        匯出與歷史記錄

        匯出格式
        PDF每頁為 2 倍解析度圖片，外觀與畫面一致，文字無法再編輯。
        PowerPoint每頁為圖片，並保留講者備註於備忘稿。
        HTML可直接用瀏覽器播放的單一檔案，按 N 可顯示備註。
        歷史記錄
        • 點左上角的 開啟側邊欄，可搜尋、重新開啟或刪除過去的簡報。
        • 記錄存放在伺服器並依帳號分開，換電腦或瀏覽器登入同一帳號即可接續使用；每個帳號最多保留 200 筆。
        • 「新增簡報」可清空目前內容，回到輸入步驟。
